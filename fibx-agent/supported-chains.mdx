FibX supports four EVM-compatible chains. Commands that accept `--chain`
default to **Base**; portfolio spans all supported chains, while Aave always
targets Base.

## Chain Overview

| Chain    | Native Token | Chain ID | CLI Flag           | Aave V3 |
| -------- | ------------ | -------- | ------------------ | ------- |
| Base     | ETH          | 8453     | `--chain base`     | Yes     |
| Citrea   | cBTC         | 4114     | `--chain citrea`   | No      |
| HyperEVM | HYPE         | 999      | `--chain hyperevm` | No      |
| Monad    | MON          | 143      | `--chain monad`    | No      |

## Selecting a Chain

Use `--chain` with chain-aware commands such as `quote`, `status`, `balance`,
`send`, `trade`, and `tx-status`. Aave commands always target Base, `portfolio`
queries every supported chain, and `address`/`wallets` are chain-independent.

```bash
# Explicit chain selection
npx fibx@latest trade 0.1 ETH USDC --chain base
npx fibx@latest balance --chain monad

# Shorthand with -c
npx fibx@latest balance -c citrea
```
